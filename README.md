One line of earned pride: "She fixed the neighbor's leaking sink with a
wrench she'd never held before, and when the water stopped, she stood there
a moment longer, just listening to the quiet." The program writes it to
`/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network. Two runs produce byte-identical output.
